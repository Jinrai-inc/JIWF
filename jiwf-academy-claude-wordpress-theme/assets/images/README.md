# Theme image assets

Drop the following files into this folder. The theme uses each as the default
when the matching Customizer setting is not yet filled in.

| Filename | Used by | Recommended size |
| --- | --- | --- |
| `logo.png` | Site logo (Customizer → Site Identity → Logo, or upload here for the brand fallback) | 1200×1200 (transparent PNG) |
| `hero-fuji-himalaya.jpg` | Front-page hero (full screen) | 2400×1400 |
| `fuji.jpg` | Locations preview — left card; Story trio — Stillness | 1600×1200 |
| `himalaya.jpg` | Locations preview — right card; Story trio — Grandeur | 1600×1200 |
| `learning.jpg` | Story trio — Wisdom (interior / circle photo) | 1600×1200 |

Once uploaded, editors can override any of them through
**Appearance → Customize → JIWF Academy → Home Page Imagery** (which writes to
the WP media library directly).
